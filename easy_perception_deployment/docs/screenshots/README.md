# EPD Release Screenshot Evidence

Store reviewed release/demo screenshots in this directory when preparing a tagged handoff. Source-control screenshots are optional; the target-machine evidence set may also be archived externally with the acceptance JSON and diagnostics bundle.

Recommended filenames:

```text
01_launcher.png
02_deploy_camera_truth.png
03_camera_assistant.png
04_model_manager.png
05_live_perception.png
06_3d_inspector.png
07_profiles_replay.png
08_performance_backends.png
09_workcell_contract.png
10_release_acceptance.png
```

Each screenshot should make the relevant state readable. Do not crop away warning/error state merely to make a demo look successful.

Before committing or sharing screenshots, review for:

- usernames/home paths;
- customer/project names;
- proprietary workcell imagery;
- model filenames that should remain private;
- network/device identifiers;
- other sensitive information.

A screenshot is supporting evidence only. Machine-readable acceptance/replay/diagnostic artifacts remain the stronger reproducibility record.
